# Middleware

This folder covers Harrow middleware, security middleware, and observability
integration.

- [Middleware Architecture](./middleware.md): middleware model, execution order, runtime-agnostic design, and available middleware.
- [Security](./security.md): security headers, CORS, body limits, timeout guidance, sessions, rate limiting, and operational recommendations.
- [Observability](./observability.md): request IDs, tracing, route labels, metrics status, and deployment notes.

For server-level timeout and limit behavior, see [Server Lifecycle](../server/lifecycle.md) and [Connection Safety](../server/connection-safety.md).
