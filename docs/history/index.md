# History

This folder contains historical material: engineering journals, old strategy
notes, external reviews, benchmark archaeology, and visual assets.

Historical docs are useful for understanding why decisions were made, but they
are not current product commitments unless a current doc explicitly references
them.

- [Engineering Progress Article](./article.md): chronological engineering log and benchmark narrative.
- [Old Docs](./old/): previous strategy notes, middleware plans, reviews, migration notes, and profiling docs.

Current docs live in the subject folders from the [root docs index](../).
